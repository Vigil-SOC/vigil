# Forensic Analysis Workflow

Examine a confirmed incident forensically. Acquire evidence without modifying the originals and record its custody. Characterise the malware and the network activity it produced. Reconstruct a master timeline the report can rest on. Produce documentation that survives legal and compliance scrutiny.
