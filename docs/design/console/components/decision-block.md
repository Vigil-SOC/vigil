# Decision block
Card with 1px `poor-ln`. Order: header line (blinking dot, "Needs your decision · 4 min 12 s left", `poor` 700) → ask as verb + object (18/700) → two-column facts (Why it stopped, with the limit link; If you do nothing) → four tiles (Vigil recommends + confidence word; Sources agree/disagree + reviewer line; What it affects; Seen before) → strongest for / against rows (open Evidence at that row) → action bar: Hold to approve · Approve narrower · Reject · Hold, plus the hint "Know something the agents don't? Tell them below". Sub-panels (alternatives, reject reasons, hold reason + duration) open inline below the bar, one at a time.
