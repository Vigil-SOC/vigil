# Citation chip
22px, radius 999, 1px `ac-ln`, `ac-bg`, 11px mono: "step 3 · CrowdStrike". Hover inverts to `ac` fill. Click opens the Evidence tab with that row highlighted (`ac-bg`). Appears in any answer from the record. An id of the case's evidence, alerts or explanations that the answer writes is drawn as its chip where it stands in the text (an alert as "alert · <title>", opening the alert in a new tab; an explanation as "explanation · <statement>", opening the Explanations tab), and nowhere else: there is no row of chips under the answer (#2285, #2565). The kind word the answer wrote just before an alert or explanation chip ("the alert dl-005") is dropped, so it never reads "alert alert · …".

Every row on a case reads differently. A row from before the first step (a deployment blind spot) names no step: "blind spot". Rows that would share "step · source" add the first words where their own texts part, cut to fit ("step 3 · CrowdStrike · spawned by…" and "step 3 · CrowdStrike · invoked…" for two rows that both begin "rundll32.exe"); a label no other row has stays as it is.
