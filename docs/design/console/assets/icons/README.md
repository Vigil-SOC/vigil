# Icons

82 line icons, 24×24 viewBox, 1.8 stroke, round caps and joins, `currentColor`. Render at 13–16px in UI. Product-specific icons: `wall` (Fleet Wall), `coverage`, `triage`, `cases`, `agents`, `sparkle` (Ask Vigil), `expand`/`shrink` (case drawer ↔ full page).

Vendor marks are in `../logos/` — use the vendor logo, never a generic icon, for a data source.

`icons.json` holds the same paths keyed by name for direct use in code.
