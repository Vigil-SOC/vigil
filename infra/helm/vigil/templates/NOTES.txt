Vigil SOC has been installed in namespace {{ .Release.Namespace }} as release "{{ .Release.Name }}".

1. Wait for pods to come up:

   kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }} -w

2. The schema upgrade runs as Jobs on install and upgrade. App pods are not
   Ready until it has finished. Check it:

   kubectl get jobs -n {{ .Release.Namespace }} -l app.kubernetes.io/component=upgrade

3. Access the backend API:

{{- if .Values.ingress.enabled }}
   Ingress is enabled. Point DNS at your ingress controller and visit:
{{- range .Values.ingress.hosts }}
     http{{ if $.Values.ingress.tls }}s{{ end }}://{{ .host }}
{{- end }}
{{- else }}
   kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "vigil.backend.fullname" . }} {{ .Values.backend.service.port }}:{{ .Values.backend.service.port }}
   # Then open http://localhost:{{ .Values.backend.service.port }}
{{- end }}

4. Run the smoke test:

   helm test {{ .Release.Name }} -n {{ .Release.Namespace }}

{{- if eq (.Values.config.DEV_MODE | toString) "true" }}

⚠️  WARNING: DEV_MODE is enabled. Authentication is BYPASSED and every request
   acts as a mock admin user. Do NOT expose this deployment publicly. Flip
   config.DEV_MODE to "false" and set secrets.jwtSecretKey to enable real auth.
{{- else }}

No default admin account ships. On first visit the web UI opens a bootstrap
screen (POST /api/auth/bootstrap) where you create the admin with a password
of your choosing; it closes as soon as one account exists. The screen asks for
a setup code, which the backend logs once its database is ready:

   kubectl logs -n {{ .Release.Namespace }} deploy/{{ include "vigil.backend.fullname" . }} | grep 'First-run setup code:'
{{- end }}

{{- $medic := .Values.medic | default dict }}
{{- if eq ($medic.enabled | toString) "true" }}
{{- $user := dig "gateway" "viewer" "username" "<medic.gateway.viewer.username>" $medic }}
{{- $tok := include "vigil.medicGateway.tokenSecret" . }}
{{- $ns := .Release.Namespace }}

Medic is on. Until its gateway has a token it reports no_credential. Once the
backend is up, mint the token (this creates the Viewer service account {{ $user }}
if needed; docs/medic/enable.md) and store it in the Secret {{ $tok }}.
The token goes on a pipe, never on a command line. The gateway picks it up within
about a minute, no restart; any old password stops working once the token is
used. Run it again to renew the token:

   kubectl -n {{ $ns }} exec deploy/{{ include "vigil.backend.fullname" . }} -- python -m core.auth.service_account token {{ $user }} \
     | kubectl -n {{ $ns }} create secret generic {{ $tok }} --from-file={{ .Values.medic.gateway.tokenSecret.key }}=/dev/stdin --dry-run=client -o yaml \
     | kubectl -n {{ $ns }} apply -f -
{{- end }}
